# Defensive Python Snippets

## Purpose
This repository showcases the practical application of defensive programming principles learned through GCSE OCR Computer Science and mapped to the OWASP Top 10 2025 security standards.

## Contents
* *SQL Injection Prevention:* Side-by-side contrast of vulnerable query concatenation versus secure parameterization techniques.
* *Input Sanitisation & Validation:* Python implementations of structural constraints (length checks, type checking, and white-list sanitisation) to prevent unexpected security exploits.

## Connection to Cyber Security Concepts
Writing these functions directly supports my understanding of *OWASP Top 10 2025: Application Design Flaws*. It proves that security must be designed straight into the code layout, rather than being patched on after a vulnerability is found.
